Soovee Commander 0.20.0 (test build)

iPhone and iPad
- File manager without another device: the app's own folder plus folders chosen in Files (iCloud Drive, On My iPhone, Downloads, USB and network drives).
- Fast file list for large folders, with thumbnails, list or grid view, sorting and a live filter. Return searches all subfolders (names only; iCloud files are not downloaded).
- Long-press menu: Open, Edit, Share, Copy to, Move to, Duplicate, Rename, Compress, Extract, Favorites, Properties, Delete. Swipe actions and multi-select with an action bar.
- Quick Look preview with paging through the folder, a plain-text editor, new text files, ZIP and TAR extraction, ZIP creation.
- Overview with locations, favorites, recent places and devices. Locations can be removed with a swipe; network locations are marked and show when they are unavailable.
- Copy progress sheet with a progress bar, size, speed, time left and Stop; it can be hidden while the copy continues.
- Two panels on iPad and on iPhone in landscape. The right panel is the copy/move target, with drag and drop and keyboard shortcuts (F5, F6, Cmd+Backspace, Cmd+A, Cmd+R).
- Redesigned Devices and Settings screens; the diagnostic log opens as a readable, shareable sheet.

Pairing
- When the other device has forgotten the pairing, the app offers to remove it and pair again instead of showing a TLS error.
- Pair is enabled only after all eight digits are entered.

macOS
- An update package stored only in iCloud Drive is downloaded automatically before it is checked.

Fixes
- Refused connections on Windows are reported as a forgotten pairing.
