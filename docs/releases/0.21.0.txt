Soovee Commander 0.21.0 (test build)

Android phone and Android TV
- New look matching the iPhone and iPad app: Overview, Files, Devices and Transfers with grouped sections, light and dark mode.
- Fast file list for large folders, photo and video thumbnails, list or grid view, natural sorting, live filter and search in subfolders.
- Item menu: Open, Share, Copy to, Move to, Duplicate, Rename, Compress, Extract, Favorites, Properties, Delete. Long press starts multi-select with an action bar.
- Copy progress sheet with a progress bar, size, speed, time left, Hide and Stop. Copies continue in the background with a notification.
- Favorites and recent folders, a plain-text editor, new text files, ZIP and TAR extraction, ZIP creation.
- Clear connection screens: remove a pairing and pair again when the other device has forgotten it.
- Android TV: navigation rail and full remote-control navigation with a visible focus.

All platforms
- Copying keeps file times when the system refuses extended attributes (fixes duplicate and local copy errors on Android).
- File counts read "3 items" in English.
